# Linkable Microsite Factory (Kirby)

[![Kirby Skills Collection](https://img.shields.io/badge/Kirby_Skills-Collection-blue?style=flat-square&logo=github)](https://github.com/markkirby125/kirby-skills-collection)

Generic "AI-looking" JS-rendered microsites risk being ignored by journalists (directional observation), delayed or incomplete crawling in retrieval bots/Screaming Frog, and missed LLM citations. By pairing local `Claude Code` (desktop/terminal) with persistent `notes.md` state continuity, new `$4` sale / exact-match utility domains or Wayback-vetted domains, SSR HTML rendering, automated feed/API updaters, and licensed/press-kit brand-logo assets, builders can target editorial citations without manual link-building spend (single-source case study, directional).

**Directional Benchmarks (Single-Source, Unverified):** Mike Hawley reported working across `114` websites with `56` launches (`SEO-TV.com` `21,180 → 213` keywords / `139` live pages post-Round-2 across `Learn SEO`, `Business of SEO`, and `Local SEO`; `$4` new sale domain `cheese.help` → Page 1 `"mild cheese"`, `3,000–4,200` LLM citations, `25` pages getting traffic & `11` MSN backlinks across `7` pages; `audiototext.com` `~50 → ~8,000` clicks/day via free utility centerpiece placement).

Sources: Edward Sturm Ep. 1,224 feat. Mike Hawley (`ULvVvU0fWj8`, Nov 10, 2026) & Koray Tuğberk GÜBÜR (`Af9rvlVPQCQ`, Oct 10, 2026).
