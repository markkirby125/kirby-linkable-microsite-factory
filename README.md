# Linkable Microsite Factory (Kirby)

[![Kirby Skills Collection](https://img.shields.io/badge/Kirby_Skills-Collection-blue?style=flat-square&logo=github)](https://github.com/markkirby125/kirby-skills-collection)

Generic "AI-looking" JS-rendered microsites get ignored by journalists, fail to crawl cleanly in Googlebot/Screaming Frog, and miss LLM citations. By pairing local `Claude Code` (desktop/terminal) with persistent `notes.md` state continuity, aged Wayback domains or exact-match utility domains, SSR HTML rendering, daily Python cron updaters, and high-craft authentic SVG/brand-logo assets, a non-coder can ship high-DR linkable assets with `$0` manual link-building spend.

**Directional Benchmarks (Single-Source):** Mike Hawley built `114` websites across `56` launches (`SEO-TV.com` `21,180 → 213` keywords / `139` pages; `$4` domain `cheese.help` → `3,000–4,200` LLM citations & `11` MSN backlinks; `audiotext.com` `~50 → ~8,000` clicks/day via free utility centerpiece placement).

Sources: Edward Sturm Ep. 1,224 feat. Mike Hawley (`ULvVvU0fWj8`, Nov 12, 2026) & Koray Tuğberk GÜBÜR (`Af9rvlVPQCQ`, Nov 11, 2026).
