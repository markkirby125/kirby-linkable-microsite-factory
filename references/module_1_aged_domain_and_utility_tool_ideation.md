## 1.1 Two High-Yield Asset Archetypes
1. **The Expired-Domain Clean-History Rebuild (`cheese.help` Model):**
   - Acquire cheap (`$4–$10`) expired domains on clean, non-spam histories (verify full Wayback Machine history and backlink hygiene per `../../kirby-seo-deployment/SKILL.md` Module 7 §7.10 C before buying — reject prior pharma/casino/adult pivots).
   - Rebuild the asset as a structured, clean-DOM encyclopedia/directory (`cheese.help` rebuilt from an ugly archived site into a structured cheese encyclopedia earning `3,000–4,200` LLM citations and `11 MSN` links with `$0` link-building spend; `"wild cheese"` drove traffic across `25` pages).
2. **The Exact-Match Free-Utility Microsite (`audiotext.com` / `SEO-TV.com` Model):**
   - Build single-purpose free utilities or niche directories on memorable domains (`audiotext.com` free audio/text tool growing `~50 → ~8,000` clicks/day; `SEO-TV.com` retro video-store directory built in `4–5 hours` indexing `~70 → 139` live pages with `25` pages driving traffic).

## 1.2 Keyword Narrowing & Cannibalization Splitting
1. **Cluster & Verify SERP Intent Before Building:**
   - Filter massive keyword sets down to verified, non-overlapping intent targets (e.g., `SEO-TV.com` narrowed `21,180` initial search terms down to `213` curated keywords after inspecting live SERP intent).
2. **Split Distinct Verticals to Prevent Self-Cannibalization:**
   - Never collapse overlapping modifiers onto one ambiguous page template. Create distinct page types with clear intent jobs (e.g., splitting `"Local SEO"` services/directories from `"Learn Local SEO"` educational hubs).
3. **Interactive Utility Selection:**
   - Prioritize tools users bookmark and journalists cite: interactive maps (GTA VI Leonida map built overnight), directories with unique Easter eggs/randomizers (`SEO-TV.com` `"randomize me"` button + episode counters across `1,224` episodes), or friction-free zero-signup converters (`audiotext.com`).
